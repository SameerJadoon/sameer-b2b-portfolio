# Sameer Jadoon — B2B Portfolio

Premium Next.js portfolio for B2B Lead Generation & Cold Email services.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

Import this GitHub repository into Vercel. Vercel should detect Next.js automatically.

## Important
